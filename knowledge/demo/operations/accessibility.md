# Tell reception what would help

If an accessibility adjustment would make a visit easier in the CareFlow Demo Clinic scenario, contact reception during staffed hours and describe the practical arrangement being requested. The fictional team can discuss what may be possible, but this reference does not promise a particular facility, equipment, accessible route, or accommodation. No physical address or building features are specified for the demo.

Reception's illustrative window is Monday through Saturday, 09:00–17:00 India Standard Time (IST), and it is closed Sundays and posted holidays. Appointment availability is managed in the live app and can differ from those administrative hours. If booking and an adjustment request need coordination, use the app for the slot and reception for a conversation about the request; neither channel guarantees a particular outcome.

Share only the information needed to explain the requested arrangement. The portfolio does not describe file uploads or chat records, so do not assume either feature exists. The seed directory's fictional staff—Dr. Sarah Chen, Dr. James Wilson, and Dr. Emily Rodriguez—do not imply specific accessibility expertise or real credentials.

For a real visit, verify access details directly with the actual provider before travel. This note does not assess medical needs or guarantee service availability. If a requested arrangement cannot be confirmed, do not infer that the site has the needed feature from this demo description.
