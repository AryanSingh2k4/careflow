# Use the current appointment record

For a returning visit in the CareFlow Demo Clinic demonstration, start with the live app's appointment flow and review the current details it shows. This page cannot retrieve an existing record, confirm prior attendance, or infer what a follow-up should involve. Only the live application can present currently bookable times; there are no exact upcoming dates or openings in this reference.

The fictional seed directory contains General Practice (Dr. Sarah Chen), Cardiology (Dr. James Wilson), and Pediatrics (Dr. Emily Rodriguez). These names are fictional project seed staff. The directory does not indicate whether a person should return to a particular specialty, establish clinical continuity, or suggest that the same staff member will be available. Do not use the labels to decide what care is needed.

Reception operates illustratively Monday through Saturday, 09:00–17:00 India Standard Time (IST), closed Sundays and posted holidays. These are reception hours only; app availability can differ. If a booking needs to move, make the request promptly and aim for 12 hours ahead where possible. Any new slot is subject to what the live app displays.

The portfolio does not specify payment, records, uploads, chat, or coverage. For real follow-up instructions, use the actual provider's verified communication, not this fictional operational corpus. This document is not a diagnosis or care plan.
